# Defence preparation outline

Slides and rehearsals are a later stage. Do not claim they are finished.

Suggested 15–20 minute flow: problem and target audience (2 min); demo preferences, ranking, comparison and neighbourhoods (5 min); functional core and architecture (4 min); authorization, tests and data limitations (3 min); team roles and questions (remaining time).

Be ready to explain:
1. Why a nearby campus is not the only criterion.
2. What a pure function is, using CalculateCost.
3. How changing weights changes ranking.
4. Why a missing utility bill is not zero.
5. Why missing routes and service errors are different results.
6. Why demo crowding is not a real forecast.
7. How owner access is checked on the server.
8. Which tests use actual SQLite.
9. What each participant reviewed and changed.
10. What needs to change before real deployment.
